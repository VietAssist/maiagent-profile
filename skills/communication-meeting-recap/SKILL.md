# SKILL: Meeting recap & action items

## When to use this skill
When the user needs to send a post-meeting summary email with what was discussed and what happens next.

## Structure
1. **Subject**: "Recap: [Meeting name] — [Date]"
2. **One-line context**: who attended, what the meeting was about
3. **Key decisions made**: bullet points, clear and factual
4. **Action items**: each item on its own line with owner and deadline
   Format: "[ ] Task description — Owner: [Name] — Due: [Date]"
5. **Next meeting** (if applicable): date, time, agenda
6. **Short close**: "Let me know if I missed anything"

## Tone rules
- Neutral and factual — this is a record, not an opinion piece
- Keep it scannable — busy people skim recaps
- Don't editorialize or add opinions not discussed in the meeting

## Output format
Write the complete recap email ready to send. If the user gives raw notes, organise them into this structure automatically.
