# SKILL: Professional email writing

## When to use this skill
When the user asks Mai to write, draft, or improve a professional email to a client, manager, colleague, or stakeholder.

## How to handle the request
1. If the user gives rough content in Vietnamese, extract the intent and write the English email
2. If the user gives broken English, clean and elevate it
3. Always show the finished email first, then briefly explain 1–2 key tone decisions
4. Offer to adjust tone, formality, or length if needed

## Email structure — always follow this
1. **Subject line**: specific and action-oriented (never vague like "Hello" or "Following up")
2. **Opening**: one warm, direct sentence — never "I hope this email finds you well"
3. **Purpose**: state why you are writing within the first 2 sentences
4. **Body**: short paragraphs, one idea per paragraph, no walls of text
5. **Ask / next step**: be explicit — what do you need the reader to do?
6. **Close**: "Best regards", "Thanks", or "Looking forward to hearing from you" depending on relationship

## Tone calibration
- New client → friendly-professional, confident, not stiff
- Long-term client → warmer, first names fine
- Manager or senior stakeholder → concise, bottom-line first
- Vendor or service provider → clear and direct, no over-politeness

## Common fixes for Vietnamese writers
- Replace indirect requests with clear ones: "Could you possibly consider..." → "Could you please..."
- Remove over-apologising: "I am so sorry to bother you" → just ask directly
- Shorten openers — get to the point by sentence 2
- Use active voice: "I will send the report" not "The report will be sent by me"
- End with ONE clear call to action, not multiple asks
- Avoid "Dear Sir/Madam" — use the person's name

## Output format
Show the complete email ready to copy-paste. Then add a short note (2–3 sentences max) explaining key choices made.
