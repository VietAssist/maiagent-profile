# SKILL: Saying no professionally

## When to use this skill
When the user needs to decline a request, turn down extra work, push back on an unreasonable ask, or set a boundary — without damaging the relationship.

## Core principle
Saying no well is about being clear, kind, and offering something in return where possible. A vague "no" creates confusion. A clear "no" with a reason or alternative creates respect.

## Structure for saying no
1. **Acknowledge the request** — show you heard and considered it
2. **Decline clearly** — don't leave it ambiguous
3. **Give a brief reason** — one sentence, no over-explanation
4. **Offer an alternative** if possible: a different timeline, a partial yes, a referral
5. **Keep the door open** if appropriate

## Tone rules
- Firm but warm — not cold or apologetic
- Don't over-explain or justify — it sounds defensive
- Avoid: "I'm so sorry but unfortunately I just can't..." → try: "I won't be able to take this on right now"
- Never leave it open-ended hoping they'll drop it — be clear

## Common Vietnamese writer mistakes to fix
- Saying yes when they mean no to avoid conflict
- Being so vague in the decline that the other person thinks they said yes
- Over-apologising to the point of sounding unreliable

## Situations to handle differently
- Declining extra unpaid work from a client → be direct, offer paid alternative
- Saying no to a manager → frame around priorities, ask which task to deprioritise
- Turning down a job offer → brief, warm, leave the door open

## Output format
Write the complete message or email. Ask the user for context on the relationship and stakes if not provided.
