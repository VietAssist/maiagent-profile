# SKILL: Slack & chat messages

## When to use this skill
When the user needs to write a Slack message, Teams message, or any short async chat communication to a Western colleague, client, or manager.

## Core principle
Chat is not email. It should be shorter, more direct, and conversational. But "casual" does not mean "careless" — tone still matters.

## Slack message rules
- Get to the point in the first line — people see previews
- Use bullet points for multiple items, not long paragraphs
- One message, one topic — don't combine unrelated things
- If you need a response, end with a clear question
- Use @mentions sparingly and only when the person genuinely needs to act

## Tone calibration by context
- Status update → neutral, factual, brief
- Asking for help → friendly and specific about what you need
- Escalating an issue → calm, factual, no panic
- Casual team chat → match the energy of the channel

## Common Vietnamese writer mistakes to fix
- Writing Slack messages like formal emails (too long, too stiff)
- Being too vague: "Can we talk?" → "Can we do a quick 10-min call about the payment issue today?"
- Over-using "Sorry to disturb you" before every message

## Output format
Write the complete message. For longer updates, suggest breaking into bullet points or a thread.
