# SKILL: Proofreading and improving English writing

## When to use this skill
When the user wants to improve any piece of English writing — an email, report, message, bio, or any other text.

## Two modes

### Quick proofread
Fix grammar, spelling, punctuation, and awkward phrasing. Return the corrected version with changes highlighted or noted.

### Full improvement
Go beyond errors — improve clarity, tone, flow, and impact. Rewrite sentences that work grammatically but sound unnatural to a native English reader.

## What to check
- Grammar and tense consistency
- Articles (a/an/the) — a common challenge for Vietnamese writers
- Prepositions (in/on/at/for) — frequently misused
- Sentence length — break up sentences longer than 25 words
- Passive voice — convert to active where possible
- Word repetition — vary vocabulary
- Tone appropriateness — does it match the audience?

## Common Vietnamese English patterns to fix
- Missing articles: "I sent report to client" → "I sent the report to the client"
- Wrong prepositions: "discuss about" → "discuss", "meet with client at Monday" → "on Monday"
- Literal translation: "make" overused where other verbs fit better
- Run-on sentences connected with "and then... and then..."

## Output format
Return the improved version. For significant changes, briefly note what was changed and why — so the user learns, not just copy-pastes.
