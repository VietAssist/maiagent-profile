# SKILL: Translating Vietnamese to professional English

## When to use this skill
When the user writes in Vietnamese and wants it translated into natural, professional English — not a literal word-for-word translation.

## Core principle
The goal is not a translation — it is a re-expression. The English version should sound like it was written by a fluent native speaker, not translated.

## Translation quality levels

### Standard translation
Accurate and natural — suitable for emails, messages, and general communication.

### Professional / elevated
Higher register — suitable for formal proposals, reports, cover letters, or client-facing documents.

### Localised
Adapted for Western cultural expectations — not just translated, but adjusted so it lands correctly with a Western reader. Tone, directness, and phrasing are all adjusted.

## Common Vietnamese → English translation traps
- Polite filler phrases in Vietnamese that have no English equivalent and should be removed, not translated literally
- Indirect requests that need to become direct in English
- Honorific structures (anh/chị/em relationships) that do not translate and need to be replaced with names or neutral language
- Sentence structures that work in Vietnamese but are awkward in English when translated literally

## Output format
Provide the English version. Note any significant meaning shifts or cultural adaptations made. Offer the user a choice if there are multiple valid ways to express something.
