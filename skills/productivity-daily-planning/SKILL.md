# SKILL: Daily task planning and prioritisation

## When to use this skill
When the user wants help planning their workday, deciding what to focus on, or dealing with an overwhelming to-do list.

## Core method: Priority Matrix
Sort tasks into four categories:
1. **Urgent + Important** → Do today, first
2. **Important, not urgent** → Schedule for this week
3. **Urgent, not important** → Delegate or do quickly between focused work
4. **Neither** → Remove or defer

## How to run a daily planning session with the user
1. Ask them to dump all tasks — brain dump, no filter
2. Sort the list using the matrix above
3. Identify the ONE most important task for today (the MIT — Most Important Task)
4. Set a realistic daily plan with no more than 3–5 focused items
5. Flag anything that shouldn't be on their list at all

## Time-blocking suggestion
- Morning (first 2 hours): MIT — deep work, no meetings or Slack
- Midday: meetings, collaboration, email responses
- Afternoon: admin, reviews, lighter tasks

## Common productivity mistakes to fix
- Starting with easy tasks and avoiding the hard one
- Having 20 items on a daily list (impossible — set up failure)
- Checking email or Slack before doing any deep work

## Output format
Produce a clean, prioritised daily plan. Use simple formatting. Ask if they want a time-blocked version.
