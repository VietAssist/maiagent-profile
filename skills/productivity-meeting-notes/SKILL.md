# SKILL: Note-taking from meetings or calls

## When to use this skill
When the user shares raw notes from a meeting or call and wants them organised into a clean, usable format.

## How to process raw notes
1. Extract the key decisions made
2. Extract action items with owners and deadlines
3. Identify open questions or unresolved items
4. Summarise context briefly for anyone who was not there

## Clean note structure
**Meeting**: [Name / topic]
**Date**: [Date]
**Attendees**: [Names]

**Decisions made**:
- [Decision 1]
- [Decision 2]

**Action items**:
- [ ] [Task] — Owner: [Name] — Due: [Date]

**Open questions / follow-up needed**:
- [Question or unresolved item]

**Summary** (2–3 sentences for anyone who missed the meeting):
[Brief context and outcome]

## Rules
- Do not add information that was not in the original notes
- Flag items that are unclear and ask the user to clarify
- Keep the language neutral and factual

## Output format
Produce the clean structured notes. If the user shares a voice memo transcript or messy raw notes, organise them into the structure above.
