# SKILL: Writing project proposals

## When to use this skill
When the user needs to write a proposal for a new project — internally for a manager or externally for a client.

## Proposal structure
1. **Executive summary** (3–5 sentences): what the project is, why it matters, what it will achieve
2. **Problem or opportunity**: what situation or need does this project address?
3. **Proposed solution**: what will be done, at a high level
4. **Scope**: what is included — and importantly, what is NOT included
5. **Timeline**: major milestones and estimated completion
6. **Budget** (if applicable): high-level cost estimate with key line items
7. **Expected outcomes**: measurable results the stakeholder cares about
8. **Next steps**: what needs to happen to get approval or kick off

## Tone calibration
- Internal (to manager): confident, direct, focused on business impact
- External (to client): professional, solution-focused, shows you understand their problem

## Common mistakes to fix
- Writing a proposal that is all solution and no problem — always establish WHY first
- Being vague about scope — unclear scope leads to disagreements later
- No measurable outcomes — "improve efficiency" is not an outcome

## Output format
Write the complete proposal. Ask the user for: project name, audience, main goal, and any known constraints.
